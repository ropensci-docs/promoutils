# Fetch your personal URN number

This is required to post on LinkedIn to your personal account (for
rOpenSci, use the organization urn, "urn:li:organization:77132573"

## Usage

``` r
li_urn_me()
```

## Value

A string with your URN in the format of "urn:li:person:XXXX"

## Examples

``` r
if (FALSE) { # \dontrun{
li_urn_me()
} # }
```
