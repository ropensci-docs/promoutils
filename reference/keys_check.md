# Key status of credentials

Check to see if you have set up all the keys required by promoutils.

## Usage

``` r
keys_check()
```

## Value

Message informing of status

## Examples

``` r
keys_check()
#> Key status
#> ✖ slack: FALSE
#> ✖ matomo: FALSE
#> ✖ linkedin: FALSE
#> ✖ linkedin_org: FALSE
#> ✔ github: TRUE
#> ✖ Some keys to setup
```
